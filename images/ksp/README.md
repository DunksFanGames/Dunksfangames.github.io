# KSP images

Use this folder for Kerbal Space Program images.

Main page base filenames:
- `main-1`
- `main-2`

For each slot, upload one original image as `.png`, `.jpg`, `.jpeg`, or `.webp`. PNG is preferred for game screenshots when you want to preserve UI text and fine detail. The website displays the original file and does not resize or recompress it.

Examples:
- `main-1.png`
- `main-2.jpg`
