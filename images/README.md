# DunksFanGames image folders

Use predictable filenames so replacing a picture does not require editing HTML.

## Game Main pages

- `images/ksp/main-1.jpg`
- `images/ksp/main-2.jpg`
- `images/long-dark/main-1.jpg`
- `images/long-dark/main-2.jpg`
- `images/factorio/main-1.jpg`
- `images/factorio/main-2.jpg`
- `images/software-inc/main-1.jpg`
- `images/software-inc/main-2.jpg`

If a Main-page file is missing, the website automatically shows the normal screenshot placeholder. Upload or replace the JPG with the exact same filename and it will appear after GitHub Pages updates.

## Other images

Use `images/general/` for General images and `images/articles/` for article images. For article pictures use names such as `article-10-1.jpg`, `article-10-2.jpg`, and so on.

For best loading speed, use JPG for screenshots and keep images around 1600 pixels wide or smaller unless extra resolution is needed.
