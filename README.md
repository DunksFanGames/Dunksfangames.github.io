# DunksFanGames

A simple static fan site for articles about:

- Kerbal Space Program
- The Long Dark
- Factorio
- Software Inc

## Structure

- `index.html` — newest five article placeholders, newest first
- `page2.html` — archive page for future articles
- `styles.css` — responsive styling and accessible navigation

The five starter article cards are deliberately not links yet.

## GitHub Pages

Enable Pages from the repository settings and publish from the `main` branch root.
